\# 🇮🇳 Indian Sports Footwear E-Commerce Sales Analysis



An India-focused sports footwear e-commerce sales analysis project created using Microsoft Excel.



The project transforms a publicly available sports footwear sales dataset into an India-focused business dataset and presents the analysis through an interactive Excel dashboard.



\---



\## 📊 Project Overview



The objective of this project is to analyze sports footwear sales performance across different years, brands, categories, customer types, sales channels, products and Indian states.



The final dashboard provides a high-level view of business performance through KPIs, interactive slicers and multiple visualizations.



\---



\## 🎯 Business Objectives



\- Analyze overall revenue and order performance

\- Track yearly revenue trends

\- Identify top-performing products

\- Compare revenue across brands

\- Identify top-performing Indian states

\- Understand customer-type contribution

\- Analyze sales across different channels

\- Provide an interactive dashboard for business reporting

\## 🔄 Data Transformation



The original dataset was used as the base dataset and was then cleaned and transformed for this project.



Major transformations included:



\- Cleaning and restructuring the source data

\- Adapting the dataset to an India-focused business scenario

\- Modifying geographical information to represent Indian states

\- Structuring customer and sales attributes

\- Preparing calculated fields required for analysis

\- Creating an analysis-ready dataset for Excel PivotTables and PivotCharts



The resulting dataset is intended for analytical and portfolio purposes and should not be interpreted as real-world Indian sales data.
